# Home Maintenance Management System

A console-based Python application for managing household
maintenance tasks, repairs, service providers, and expenses.

## Features

- Add maintenance tasks
- View all maintenance records
- Search tasks
- Update task status
- Delete tasks
- Track service providers
- Track estimated and actual expenses
- Identify overdue tasks
- Generate expense reports

## Technologies Used

- Python
- JSON
- File Handling
- Functions
- Lists and Dictionaries
- DateTime

## Installation

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Navigate to the project directory:

```bash
cd Home_Maintenance_System
```

Run the application:

```bash
python main.py
```

## Data Storage

All maintenance records are stored in:

`data/maintenance.json`
